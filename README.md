# The Sims: Seasons

**The Sims: Seasons** is a custom, fan-made expansion pack for the original **The Sims** (The Sims 1).
It brings seasons to your neighborhood and adds:

- **Seasons** that change your Sims' world throughout the year
- **Over 200 new objects**
- **5 new careers**

This project was created with AI assistance.

## Compatibility

| Game version | Supported |
|---|---|
| The Sims Legacy Collection on **Steam** | Yes |
| The Sims Legacy Collection in the **EA app** | Yes |
| The Sims **Complete Collection** | Yes |

The installer detects your game version automatically. If it guesses wrong, you can pick it yourself with
**Game version...** in the install window.

## How to install

1. Go to the [**Releases**](https://github.com/SimReMods/Seasons/releases/latest) page and download
   `TheSimsSeasons-<version>.zip`.
2. Extract the zip and run **`SeasonsSetup.exe`**. Windows will ask for administrator rights, which are
   needed to write into the game folder.
3. Click **Install** and follow the instructions on screen.
4. Start The Sims and enjoy!

Close The Sims before you install. The installer will not run while the game is open.

### Good to know

- **Your saved games are backed up** to `Documents\The Sims Seasons Backups\` before every install, update or
  uninstall. These copies are only a safety net: they are never deleted or restored automatically, so you can
  copy a save back by hand if you ever need to.
- **Updating:** download the new release and run its `SeasonsSetup.exe`. It updates your existing installation.
- **Repairing:** if something seems broken, run `SeasonsSetup.exe` again and click **Reinstall**.
- **Uninstalling:** run `SeasonsSetup.exe` and choose **Uninstall**. It removes every file the expansion added and
  automatically puts back the original game files it replaced (the installer keeps a backup of them in the
  `SeasonsSetup` folder inside your game folder), leaving the game exactly as it was before.
